 TutorLink: Home Tuition Management Platform

A full-stack web app that connects students with home tutors.

 Features
- Student, Teacher and Admin roles with role-based access
- REST API with 11+ endpoints (authentication, tuition requests, messaging)
- Interactive map (Leaflet.js + OpenStreetMap) showing student requests
- Messaging between teachers and students, with a hiring workflow
- Admin dashboard with analytics

 Tech stack
Java · Spring Boot · Spring Data JPA/Hibernate · MySQL · HTML/CSS/JavaScript · Leaflet.js

 Deployment
Frontend on Netlify, backend on Render, database on Railway. (Live demo currently offline.)
